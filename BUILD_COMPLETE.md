## 🚀 How to Use

### Quick Start
1. Open `index.html` in any modern browser
2. Press `?` to see keyboard shortcuts
3. Start adding clients and staff
4. Create shifts and track compliance

### Keyboard Shortcuts
- `1-9` - Navigate to pages
- `Ctrl/Cmd + N` - Add new item
- `Ctrl/Cmd + K` - Focus search
- `?` - Show help
- `Esc` - Close modal

### Best Practices
1. Export data regularly (Settings → Export Data)
2. Use keyboard shortcuts for efficiency
3. Monitor dashboard trends
4. Keep compliance up to date
