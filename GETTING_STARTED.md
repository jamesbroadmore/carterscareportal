# Getting Started Guide
## Carters Care Platform v1.0.0

---

## Welcome to Carters Care Group Platform

This is a complete care management system designed specifically for Carters Care Group. The platform helps you manage clients, staff, scheduling, and compliance all in one place.

## Installation

### Windows Users
1. Extract the ZIP file to your desired location
2. Double-click **INSTALL.bat**
3. Follow the on-screen instructions
4. Double-click **index.html** to launch the application

### Mac/Linux Users
1. Extract the ZIP file
2. Open Terminal
3. Navigate to the folder: `cd /path/to/Carters_Care_Platform`
4. Run: `bash INSTALL.sh`
5. Open **index.html** in your browser

### Quick Open
Simply double-click **index.html** at any time to start the application!

## Main Features

### 1. Dashboard
Your command center showing real-time information:
- **Active Clients**: Total number of clients under care
- **Active Staff**: Staff members on duty today
- **Shifts This Week**: Upcoming scheduled shifts
- **Pending Approvals**: Items awaiting review
- **Quick Actions**: Shortcuts to common tasks
- **Upcoming Schedule**: Next 7 days of shifts
- **Compliance Status**: System health and certifications
- **Recent Activity**: Latest updates and changes

### 2. Clients
Manage all client information:
- Add new clients
- Track care levels (Basic, Intermediate, Advanced)
- Store contact information
- Add notes and special requirements
- View complete client list
- Edit or remove clients

### 3. Staff
Manage your team:
- Add staff members
- Set positions (Carer, Manager, Supervisor, Nurse)
- Track active/inactive status
- Store contact details
- View team directory

### 4. Schedule
Create and manage shifts:
- Assign staff to clients
- Set specific dates and times
- Add shift notes
- View weekly schedule
- Plan coverage

### 5. Compliance
Track important certifications:
- DBS Checks
- Health & Safety Training
- Safeguarding Training
- First Aid Certification
- Data Protection Training
- Generate compliance reports

### 6. Settings
Customize your organization:
- Organization name and contact info
- Export all data (backup)
- Import previously saved data
- Clear all data (reset application)

## Step-by-Step Tutorials

### Adding Your First Client

1. Click **Clients** in the left sidebar
2. Click the **+ Add Client** button (top right)
3. Enter client details:
   - **Full Name**: Client's full name
   - **Email**: (optional) Client's email
   - **Phone**: (optional) Client's phone
   - **Care Level**: Select appropriate level
   - **Notes**: Any additional information
4. Click **Save Client**
5. Your client now appears in the Clients table

### Adding Staff Members

1. Click **Staff** in the left sidebar
2. Click **+ Add Staff Member** button
3. Fill in the form:
   - **Full Name**: Employee's name
   - **Position**: Select role (Carer, Manager, etc.)
   - **Email**: Required for communication
   - **Phone**: Contact number
   - **Active**: Check if currently employed
4. Click **Save Staff**
5. Staff member is added to your directory

### Creating Your First Shift

1. Click **Schedule** in the left sidebar
2. Click **+ Create Shift** button
3. Complete the shift details:
   - **Staff Member**: Select from dropdown
   - **Client**: Select client to care for
   - **Date**: Pick shift date
   - **Start Time**: When shift begins
   - **End Time**: When shift ends
   - **Notes**: Any special instructions
4. Click **Create Shift**
5. Shift appears in your schedule

### Setting Up Compliance

1. Click **Compliance** in the left sidebar
2. Review the checklist of requirements
3. Check off items as they're completed
4. Use **Generate Report** to create documentation
5. Keep records up to date throughout the year

### Configuring Your Organization

1. Click **Settings** in the left sidebar
2. Update organization information:
   - Organization name
   - Contact email
   - Phone number
3. Click **Save Settings**
4. Your configuration is stored

## Data Management

### Backup Your Data

Regular backups protect against data loss:

1. Go to **Settings**
2. Click **📥 Export Data**
3. A JSON file downloads automatically
4. Store this file in a safe location
5. Create backups weekly or monthly

### Restore Data

To restore from a backup:

1. Go to **Settings**
2. Click **📤 Import Data**
3. Select your JSON backup file
4. Confirm the import
5. All data is restored

### Clearing Data

Only do this if you want to start fresh:

1. Go to **Settings**
2. Click **🗑️ Clear All Data**
3. Confirm (you'll be asked twice!)
4. Application resets completely

## Common Questions

**Q: Where is my data stored?**
A: All data is stored on your computer using browser storage. No data is sent online.

**Q: Can I use this on multiple computers?**
A: Yes! Export from one computer, import on another to sync data.

**Q: What if I lose my browser data?**
A: Use your backup file to restore everything. Always keep backups!

**Q: Can I print reports?**
A: Yes, use your browser's print function (Ctrl+P or Cmd+P) on any page.

**Q: How many clients/staff can I manage?**
A: Theoretically unlimited, depends on storage space available.

**Q: Is this secure?**
A: Data stays on your computer. No external connections. Very secure!

**Q: Can I access this offline?**
A: Yes! Complete offline functionality once loaded.

**Q: Do I need to install anything?**
A: No! Just open the HTML file in any modern browser.

## Troubleshooting

### Application Won't Open
- Make sure index.html file exists
- Try different browser
- Clear browser cache
- Disable browser extensions

### Data Not Saving
- Check browser storage is enabled
- Clear browser cache
- Try incognito/private mode
- Check available storage space

### Slow Performance
- Close other browser tabs
- Clear browser cache
- Update your browser
- Restart browser

### Missing Data After Restart
- Data might have been cleared
- Check if you have a backup to restore
- Use export feature regularly
